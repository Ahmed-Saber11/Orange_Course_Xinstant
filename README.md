# Orange Course X instant 🍊
A collection of projects and exercises completed as part of the **Orange X instant** intern.

## 📁 Projects

### [Marketing Performance Analysis](./Marketing%20Performance%20Analysis)
An end-to-end data analytics project: cleaning a raw marketing/product performance dataset, modeling it as a Power BI star schema, building a 24-measure KPI framework, and delivering two executive dashboards with data-driven business recommendations.

**Highlights:**
- Python data cleaning & exploratory analysis notebook
- Power BI star schema data model (fact + dimension tables)
- KPI library across Marketing, Flash Sales, Bundling, and Customer categories
- Two executive dashboards + full project documentation and presentation deck

👉 See the [project README]([./Marketing%20Performance%20Analysis/README.md](https://github.com/Ahmed-Saber11/Orange_Course_Xinstant/blob/main/Student%20Performance%20Analytics/README.md)) for full details.

### [Student Performance Analysis](./Student%20Performance%20Analysis)
An exploratory data analysis project on student exam performance investigating how factors like gender, parental level of education, test preparation, and lunch type relate to scores in math, reading, and writing.

**Highlights:**
- Data cleaning and exploratory data analysis in Python 
- Score distributions and comparisons across demographic and preparation factors
- Visual, story-driven notebook with clear business/educational takeaways

👉 See the [project README](./Marketing%20Performance%20Analysis/README.md) for full details.
